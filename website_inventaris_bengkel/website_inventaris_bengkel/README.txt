WEBSITE INVENTARIS BENGKEL TI

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder website_inventaris_bengkel di VS Code.
3. Buka index.html menggunakan browser (klik dua kali), atau gunakan ekstensi Live Server.
4. Data alat, peminjaman, dan riwayat disimpan di localStorage browser.

Fitur:
- Dashboard ringkasan total alat, stok tersedia, sedang dipinjam, dan terlambat.
- CRUD data alat (tambah, ubah, hapus).
- Form pencatatan peminjaman dengan validasi stok.
- Pengembalian alat dan pencatatan riwayat.
- Pencarian dan filter data.
- Tampilan responsif untuk desktop dan ponsel.

Catatan:
Ini adalah prototipe front-end. Data hanya tersimpan di browser/perangkat yang digunakan,
belum memakai database/server dan belum mendukung login multi-pengguna.
Untuk penggunaan bengkel sesungguhnya, tahap berikutnya adalah menghubungkan aplikasi
ke PHP/Laravel dan MySQL serta menambahkan autentikasi dan pencatatan petugas.
